# Security

sand3d runs the programs it is given: a sand3d program is Python, with the rights of the
process that runs it. Run programs you did not write, a model's included, in a sandbox.

To report a vulnerability in the library itself, do not open a public issue: use GitHub's
private vulnerability reporting (Security → Report a vulnerability) or write to
thibault.neveu@sandflow.ai. We answer within a week.
